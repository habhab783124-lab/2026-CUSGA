# 记忆整理检查清单
Version: 1.0.0
Updated: 2026-05-12

## 什么时候做一次整理
- 连续几轮同一主题后文档入口变乱
- `memory-index.paths.txt` 与真实文件不一致
- skill 清单和 skill 目录不一致
- 一大阶段任务结束，准备进入下一阶段
- 记忆文档出现重复、冲突或失真

## 整理范围
### L1
- `docs/current-task-card.md`

### L2
- `td-memory-main.md`
- `td-memory-architecture.md`
- `td-memory-rules-and-history.md`
- `td-agent-development-playbook.md`
- `td-agent-task-intake-protocol.md`
- `td-memory-hygiene-and-lifecycle.md`
- `memory-index.paths.txt`

### workflow / skill 文档
- `workflow-context-packages.md`
- `context-compression-and-knowledge-plan.md`
- workflow skill 集

### L3
- 只检查入口是否清晰
- 不重写原始历史

## 固定整理步骤
1. 检查任务卡是否过期
2. 给主记忆去重
3. 给规则与历史收口
4. 检查文件指南和索引
5. 检查 skill 层
6. 判断哪些内容该从 L1 提炼进 L2
7. 判断哪些只该留在 L3

## 整理目标
- 去重
- 消解冲突
- 保留最短、最准确、最可执行的版本
- 不丢失用户明确认可过的规则和结论
