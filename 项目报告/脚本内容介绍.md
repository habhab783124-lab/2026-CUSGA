# 脚本内容介绍

## 说明

本文档按当前项目中实际存在的 `.cs` 脚本进行分类整理，说明哪些脚本涉及以下内容：

- 角色控制
- NPC 近距离交互
- 对话框逐字显示
- 对话 UI 跟随 NPC
- 相关演示场景和编辑器搭建工具

当前项目中的脚本列表：

- `Assets/PlayerController.cs`
- `Assets/PlayerMovement.cs`
- `Assets/IInteractable.cs`
- `Assets/NPCInteractable.cs`
- `Assets/DialogueManager.cs`
- `Assets/TypewriterEffect.cs`
- `Assets/Editor/DemoNpcSetupUtility.cs`

## 1. 角色控制

### 相关脚本

- `Assets/PlayerController.cs`
- `Assets/PlayerMovement.cs`

### 说明

- `PlayerController.cs` 是当前角色控制主脚本，负责：
  - 左右移动
  - 角色朝向翻转
  - 动画参数更新
  - X 轴边界限制
  - 对话期间冻结角色移动
- `PlayerMovement.cs` 是兼容层，继承 `PlayerController`，本身不增加新逻辑，但仍属于角色控制相关脚本。

## 2. NPC 近距离交互

### 相关脚本

- `Assets/IInteractable.cs`
- `Assets/NPCInteractable.cs`

### 说明

- `IInteractable.cs` 定义了统一交互接口，包括：
  - 交互提示文本
  - 是否可交互
  - 交互触发入口
- `NPCInteractable.cs` 是当前 NPC 近距离交互的核心实现，负责：
  - 玩家进入 `Trigger` 范围后显示交互提示
  - 玩家离开范围后关闭提示
  - 按 `E` 键触发 NPC 对话
  - 对话结束或中断时恢复状态

## 3. 对话框逐字显示

### 相关脚本

- `Assets/NPCInteractable.cs`
- `Assets/DialogueManager.cs`
- `Assets/TypewriterEffect.cs`

### 说明

- `NPCInteractable.cs` 内部直接实现了 `TypeLine` 协程，是当前场景里 NPC 对话逐字显示的重要实现脚本。
- `DialogueManager.cs` 提供了全局单例式对话管理，负责：
  - 逐字打印
  - 左键跳过当前句
  - 左键推进下一句
  - 多组对话排队
- `TypewriterEffect.cs` 是对 `DialogueManager` 的触发封装，用来把预设台词提交给全局对话系统播放。

## 4. 对话 UI 跟随 NPC

### 相关脚本

- `Assets/NPCInteractable.cs`
- `Assets/Editor/DemoNpcSetupUtility.cs`

### 说明

- 当前项目里没有单独的“UI 跟随脚本”。
- 对话 UI 跟随 NPC 的实现方式，主要是把提示 UI 和对话 UI 作为 NPC 的子物体挂在层级下，让它们随 NPC 一起移动。
- `NPCInteractable.cs` 负责控制这些 UI 根节点的显示与隐藏，包括：
  - `interactPromptRoot`
  - `dialogueCanvasRoot`
- `DemoNpcSetupUtility.cs` 会在编辑器中自动创建：
  - NPC 头顶的交互提示 UI
  - NPC 头顶的 World Space 对话 Canvas
  这些对象都会作为 NPC 子物体生成，因此天然跟随 NPC。

## 5. 相关演示场景和编辑器搭建工具

### 相关脚本

- `Assets/Editor/DemoNpcSetupUtility.cs`

### 说明

- `DemoNpcSetupUtility.cs` 是当前项目最直接的演示搭建工具脚本。
- 它在 Unity 编辑器菜单中提供了快速重建演示对象的能力，主要用于：
  - 重建可移动角色 `NPC`
  - 重建可交互 NPC `NPC2`
  - 自动挂载 `PlayerController`、`NPCInteractable`
  - 自动创建交互提示 UI 和对话 UI
  - 为 demo 写入测试台词

### 补充说明

- 演示场景本体是 `Assets/Scenes/SampleScene.unity`，但它不是 `.cs` 脚本文件，因此未纳入本次“脚本分类”主列表。
